Decisions API · SystemOne API05
The algorithm · every engine

Five steps, one pass per question.

1

Render

One prompt per question: state + question + lettered options.

2

Check labels

Each label (A, B, C) must be exactly one token, or the model is refused.

3

Forward pass

Prefill. The shared state prefix is cached across questions.

4

Keep labels

Take the logits at the answer position; drop all other tokens.

5

Softmax

Normalise over the labels only → probabilities → typed answer.
