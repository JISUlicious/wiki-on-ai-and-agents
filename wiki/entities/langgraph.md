# LangGraph

A [[langchain|LangChain]] library for building agents as cyclical state graphs. The launch post is dated 17 January 2024; the repository was created in August 2023. The post presents it as more controlled than the simple loop behind `AgentExecutor`, the same logic it credits for projects like [[autogpt|AutoGPT]]. See [[langchain-history-2024-2025]].
