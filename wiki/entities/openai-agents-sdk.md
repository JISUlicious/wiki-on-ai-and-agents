# OpenAI Agents SDK

[[openai|OpenAI]]'s open-source framework for multi-agent workflows, released on 11 March 2025. Its primitives include agents, handoffs and guardrails, and its tools can include [[mcp|MCP]] servers.

## Lineage

It replaces Swarm, OpenAI's experimental SDK (repository created 2024-02-22). The Swarm README calls it a production-ready evolution. See [[new-tools-for-building-agents-openai-2025]].
