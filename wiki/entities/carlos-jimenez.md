# Carlos E. Jimenez

Researcher at [[princeton-university|Princeton]] and first author of "[[swe-bench-jimenez-2023|SWE-bench: Can Language Models Resolve Real-World GitHub Issues?]]" (ICLR 2024). That paper made [[swe-bench]] the standard benchmark for language models as software engineers.

## In this wiki

- **[[swe-bench-jimenez-2023|SWE-bench]]** (2023) — first author. 2,294 task instances built from real GitHub issues and their merged pull requests across 12 Python repositories. The paper also released SWE-Llama, the SWE-bench-train set and the 300-task SWE-bench Lite subset. Its construction pipeline seeded [[swe-bench-live]] and [[swe-gym]].
- **[[swe-agent-yang-2024|SWE-agent]]** (2024) — equal-contribution co-author with John Yang, introducing the [[agent-computer-interface]] that [[swe-agent]] uses on SWE-bench.

Note: not to be confused with [[bernal-jimenez-gutierrez]] (HippoRAG), a different researcher.
