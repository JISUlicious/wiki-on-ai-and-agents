# Claude

Claude is the family of [[decoder-only-transformer|decoder-only Transformer]] LLMs produced by [[anthropic|Anthropic]]. Named after Claude Shannon. The Claude family has gone through several major generations (each with multiple size tiers — typically Haiku / Sonnet / Opus, smallest to largest):

| Generation | Released |
|---|---|
| Claude 1 | March 2023 |
| Claude 2 | July 2023 |
| Claude 2.1 | November 2023 |
| Claude 3 (Haiku / Sonnet / Opus) | March 2024 |
| Claude 3.5 Sonnet | June 2024; updated October 2024 |
| Claude 3.5 Haiku | October 2024 |
| Claude 3.7 Sonnet | February 2025 |
| Claude 4 (Sonnet / Opus) | mid-2025 |
| Claude Sonnet 4.5 | early 2026 (studied in [[emotion-concepts-anthropic-2026]]) |
| Claude 4.6 Sonnet, Claude 4.7 Opus, Haiku 4.5 | 2025–2026 |
| [[claude-opus-4-8\|Claude Opus 4.8]] | 2026 — enables [[dynamic-workflows]] in [[claude-code]] |

Architectural details are not officially disclosed. Like [[gpt-4]], Claude is a closed-weights model accessed via the [[anthropic|Anthropic]] API or the **Claude.ai** product.

## Notable capabilities

- Strong on coding and reasoning (powers Claude Code, Cursor, and many other coding tools).
- Native [[tool-use|tool use]] / [[function-calling|function calling]] via a structured API.
- Long context (up to 200k tokens in the 3.x generation; 1M-token variants from 4.x).
- Multimodal (image input in 3.x onwards).
- [[constitutional-ai|Constitutional AI]] training — preference data partially generated by self-critique against a written set of principles.

## Safeguards and misuse, as documented in 2026

Anthropic's September 2026 [[anthropic-threat-intelligence-report-september-2026|threat report]] records which Claude models were misused and what was changed in response.

- **Models misused**: Haiku, Sonnet and Opus. The report found no misuse involving Fable or Mythos-class models, with one exception, a distillation campaign that tried Fable and gave up. Mythos is not publicly accessible, so its absence mostly reflects access, not safeguards.
- **Fable 5 launched with stronger safeguards** on dual-use biological queries and on cyber tasks, and alongside strengthened classifiers for detecting capability extraction.
- **Reasoning is summarized** before Claude responds, so harvested transcripts are less useful as training data.
- **Thinking signatures** return a reference to the raw reasoning, not the reasoning itself. Attackers defeated this by replaying the signature in a new session.
- **Preserved thinking**, introduced with Fable 5.1, stops new API accounts from altering the context that precedes Claude's encrypted reasoning.

See [[illicit-distillation]] and [[ai-enabled-cyber-operations]].
