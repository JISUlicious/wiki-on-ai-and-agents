# Operator

[[openai|OpenAI]]'s browser-using agent, released as a research preview on 23 January 2025 and powered by the Computer-Using Agent model. The same model later powered the computer-use tool in the Responses API. See [[introducing-operator-openai-2025]] and [[computer-use-agent]].
