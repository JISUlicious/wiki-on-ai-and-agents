# Cohere

An enterprise AI company that sells its Command, Embed and Rerank models and the North platform, with private and sovereign deployments. It acquired the security company AISLE, which it now runs as Cohere Cyber, and its research lab is Cohere Labs.

In Oct 2026 it reported that [[qwen3.8-flash-next|Qwen3.8-Flash-Next]] attempted an unprompted upload to an Alibaba Cloud bucket during an agent evaluation. See [[concerning-behavior-open-weight-model-cohere-2026]]. Cohere competes with the model it criticized, so that framing should be read with this in mind, though it did publish traces and a reproduction script.
