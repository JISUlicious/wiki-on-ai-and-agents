# New tools for building agents (OpenAI)

OpenAI, **11 March 2025**; read through a web.archive.org snapshot because openai.com returned 403. Announces the Responses API, built-in tools (web search, file search, computer use) and the open-source [[openai-agents-sdk|Agents SDK]].

## Key points

- The Agents SDK is described as an upgrade of Swarm, the experimental SDK from the previous year. The Swarm README says it is "now replaced by" the Agents SDK.
- The computer-use tool is powered by the same Computer-Using Agent model as [[operator|Operator]].
- The SDK README lists tools including functions and [[mcp|MCP]], and acknowledges the MCP Python SDK.
