# Improving agent with semantic search

6 November 2025. [[cursor|Cursor]] argues against relying on grep alone, using its own embedding model and index.

- Offline: 12.5% higher accuracy on average in answering questions (6.5%–23.5% by model).
- A/B test: code retention up 0.3% with semantic search, and 2.6% on codebases with 1,000 or more files. Dissatisfied follow-ups rose 2.2% without it.

These are Cursor's own measurements, and Cursor sells the indexed product. Baselines are not given, so the gains can't be read as absolute accuracy.
