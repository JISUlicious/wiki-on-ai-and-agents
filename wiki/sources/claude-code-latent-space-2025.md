# Claude Code: Anthropic's Agent in Your Terminal

Interview with Cat Wu and Boris Cherny, 7 May; the year is inferred from the Claude Code timeline. It is the main first-hand account of [[claude-code]]'s origin found so far.

- **Origin (00:02:04):** "There was no master plan." It began as an experiment through the public API, and became useful once it could use the terminal and code.
- **[[project-memory|CLAUDE.md]] (00:09:36):** the team knew the memory literature and products and "wanted to be inspired" by them, but shipped the simplest thing: a file read into context. An interviewer, not the team, compares it to Cursor rules (00:09:26).
- **Other tools (00:10:39):** asked about Cursor, Devin and Aider, Cherny says the team uses and likes them, and describes Claude Code as rawer. This is a comparison, not a statement of influence.
- **RAG (00:45:30–00:46:20):** see [[cherny-agentic-search-statements]].
