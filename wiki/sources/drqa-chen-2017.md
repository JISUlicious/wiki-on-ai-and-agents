# Reading Wikipedia to Answer Open-Domain Questions (DrQA)

[arXiv:1704.00051](https://arxiv.org/abs/1704.00051), March 2017. Combines a search component using bigram hashing and TF-IDF matching with a recurrent network that finds answers in Wikipedia paragraphs. It is an early retrieve-then-read pipeline. [[dpr-karpukhin-2020|DPR]] (p. 1) cites it for this two-stage framing.
