# Hermes Agent Self-Evolution

A separate [Nous Research repository](https://github.com/NousResearch/hermes-agent-self-evolution), created 2026-03-09, that optimizes [[hermes-agent|Hermes Agent]] skills using [[dspy|DSPy]] and [[gepa-agrawal-2025|GEPA]].

## Key points

- The README names GEPA as its engine and cites its ICLR 2026 Oral status. It also lists Imbue's Darwinian Evolver for code.
- Only Phase 1, skill files, is implemented. Tool descriptions, system prompts and code are planned.
- **This is not the main learning loop.** Hermes's README describes skills created and improved during use, with no research citation. A code search of `hermes-agent` for GEPA surfaced only false matches on the first page, and its results were not exhausted, so this repository is the only confirmed GEPA link.
