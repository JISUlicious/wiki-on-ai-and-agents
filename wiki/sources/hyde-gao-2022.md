# Precise Zero-Shot Dense Retrieval without Relevance Labels (HyDE)

[arXiv:2212.10496](https://arxiv.org/abs/2212.10496), December 2022. An instruction-following model such as InstructGPT writes a hypothetical document for the query, and that document is embedded for retrieval. Page 1 cites [[dpr-karpukhin-2020|DPR]] as dense retrieval. See [[hyde]].
