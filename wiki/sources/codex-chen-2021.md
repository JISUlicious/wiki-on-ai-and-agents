# Evaluating Large Language Models Trained on Code

[arXiv:2107.03374](https://arxiv.org/abs/2107.03374), July 2021. Introduces Codex, a GPT model fine-tuned on public GitHub code. A distinct production version powers [[github-copilot|GitHub Copilot]] (p. 1). On HumanEval it solves 28.8% of problems, against 0% for GPT-3. This is code generation, not tool calling. See [[openai-codex]].
