# Building a better repository map with tree-sitter

22 October 2023. [[aider|Aider]] sends the model a concise [[repo-map|map]] of the repository, built with tree-sitter and ranked with a graph algorithm. It replaces an earlier ctags version. The post presents no embeddings, so it is a third approach beside vector retrieval and grep.
