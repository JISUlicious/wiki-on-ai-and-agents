# Cursor early changelog

Archived changelogs.

- Earliest entry in the snapshot: v0.0.37, 14 March 2023. This is not the first release, so the first public date remains unconfirmed.
- Codebase Context v1: version 0.2.26, early June 2023 (between entries of 3 and 6 June).
- Stable Indexing v0.1 in September 2023; an embeddings index for codebase queries is named in notes dated 5 October 2023.
- Nightly "agents" release on 6 July 2023, which the team said it held back from general release.
- Version 0.43, 24 November 2024: an early agent in Composer that picks its own context and uses the terminal.
